# Solana Checkout Demo

Web app para conectar uma carteira Solana, verificar o saldo e enviar uma transação de teste na rede Devnet.

Web app to connect a Solana wallet, check the balance, and send a test transaction on the Devnet network.

## Sobre

Projeto simples para demonstrar a integração entre uma interface web e carteiras Solana.

Simple project to demonstrate the integration between a web interface and Solana wallets.

## Funcionalidades

- Conexão com Phantom ou Solflare
- Verificação de saldo
- Envio de transação de exemplo
- Confirmação da transação na Devnet
- Interface responsiva com Vue e Tailwind

## Como usar

### Português

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie a aplicação:

   ```bash
   npm run dev
   ```

3. Abra o endereço local exibido no terminal.
4. Conecte sua carteira.
5. Confirme a transação de teste.

### English

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app:

   ```bash
   npm run dev
   ```

3. Open the local address shown in the terminal.
4. Connect your wallet.
5. Confirm the test transaction.

## Tecnologias

- Vue 3
- TypeScript
- Vite
- Tailwind CSS
- Solana Web3.js
- Wallet Adapter

## Importante

- O projeto usa Solana Devnet, não Mainnet.
- A transação é apenas de demonstração.
- Não há chave privada no repositório.

- The project uses Solana Devnet, not Mainnet.
- The transaction is for demo purposes only.
- There is no private key in the repository.
